# QUY TẮC QUẢN LÝ GIT

1. **Nhánh chính:** `main` (chỉ chứa code đã hoàn thiện), `develop` (nhánh phát triển chính).
2. **Quy tắc đặt tên nhánh tính năng:** `feature/<ten-tinh-nang>` (Ví dụ: `feature/auth-api`, `feature/product-crud`).
3. **Quy tắc đặt tên nhánh tài liệu:** `docs/<ten-tai-lieu>`.
4. **Quy tắc commit:** `<type>: <description>` (Ví dụ: `feat: add user login API`, `docs: update de cuong`).
