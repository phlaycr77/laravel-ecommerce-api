# Biên bản rà soát tiến độ số 02 – Chốt Mốc 1

* **Đề tài**: A. Thương mại điện tử (Website bán sách, thanh toán khi nhận hàng COD)
* **Hình thức thực hiện**: Cá nhân (1 thành viên – phụ trách toàn bộ Backend RESTful API & CSDL, bỏ qua Frontend, kiểm thử/demo qua Postman theo xác nhận của Giảng viên).
* **Thời điểm rà soát**: Cuối tuần 1 (Mốc 1 – Bảo vệ thiết kế).

## 1. Kết quả đã hoàn thành trong Sprint 1
* Khởi tạo repository `laravel-ecommerce-api`, thiết lập nhánh `main`, `develop` và quy ước commit.
* Dựng khung kiến trúc phân lớp Laravel (`Controller` $\rightarrow$ `Service` $\rightarrow$ `Repository` $\rightarrow$ `Model`).
* Cài đặt xác thực JWT (`auth:api`) cho các API `register`, `login`, `me`, `logout`.

## 2. Các hạng mục Mốc 1 bổ sung hoàn thiện cuối tuần
* Cập nhật nhãn các thẻ chưa hoàn tất từ `S1` sang `S2` trên Trello kèm ghi chú lý do điều chỉnh phạm vi cá nhân.
* Hoàn thiện các đầu mục còn thiếu trước khi gắn tag `v0.1`:
  1. Bổ sung migration cột `role`, `is_active` và middleware phân quyền `TM-04` (`CheckAdminMiddleware`) chặn tài khoản khách hàng gọi API `/api/admin/*`.
  2. Hoàn thiện `DatabaseSeeder` nạp dữ liệu mẫu cho 3 tài khoản (`admin`, `customer` hoạt động, `customer` bị khóa), 3 danh mục và 6 đầu sách.
  3. Bổ sung tài liệu `docs/use-case.md` (Use Case diagram, đặc tả 3 Use Case cốt lõi và Sequence diagram luồng đặt hàng COD).
  4. Xuất sơ đồ kiến trúc phân lớp `docs/architecture.png`.
  5. Cập nhật nhật ký `AI-02` kèm link Pull Request trên GitHub.

## 3. Kế hoạch triển khai Sprint 2 (Hạn Thứ 2, Tuần 2)
* Hoàn thiện nhóm API xem danh sách, tìm kiếm và lọc sách (`TM-01`, `TM-02`).
* Hoàn thiện nhóm API quản lý danh mục và sách cho Admin (`TM-11`, `TM-12`).
* Hoàn thiện API giỏ hàng (`TM-05`) và lưu bộ request kiểm thử vào thư mục `postman/`.
